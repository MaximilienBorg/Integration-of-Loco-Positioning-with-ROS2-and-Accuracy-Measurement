# Integration-of-Loco-Positioning-with-ROS2-and-Accuracy-Measurement
ROS 2 architecture and data analysis for autonomous indoor multi-robot tracking. Implements a Sim-to-Real pipeline enabling a Crazyflie 2.1 nano-UAV to track a TurtleBot 4 UGV by fusing absolute Ultra-Wideband (UWB) positioning (LPS TDoA3) with decentralized middleware (DDS QoS) under WSL 2.
